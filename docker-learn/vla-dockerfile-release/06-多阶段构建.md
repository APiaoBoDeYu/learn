# 06 多阶段构建

> 另见：[brain-service 篇第 3 章（含 RUN --mount）](../brain-service-docker-deploy/03_multistage_and_targets.md)、[lab03](../brain-service-docker-deploy/code/lab03_multistage/)

## 要解决的问题

第 01 章提到，上层删不掉下层的数据。如果在同一个阶段里：

```dockerfile
COPY . /src                     # 第 1 层：完整源码，含测试、文档
RUN rm -rf /src/tests /src/docs # 第 2 层：只是加了"已删除"标记
```

最终镜像体积不会变小，被删的文件也还能从镜像里导出来。

多阶段构建的思路是：在一个临时阶段里随便拷、随便删，整理好之后，只把结果拷进一个全新的阶段。

## 语法

```dockerfile
FROM python:3.12-slim AS builder         # 阶段 1，命名为 builder
COPY . /src
RUN 整理文件到 /export

FROM python:3.12-slim AS release         # 阶段 2，从全新的基础镜像开始
COPY --from=builder /export /app         # 只从 builder 拿 /export
```

- `FROM ... AS 名字`：开始一个新阶段并命名。
- 每个 `FROM` 都从全新的文件系统开始，前一阶段的文件、`ENV`、`WORKDIR` 都不继承。
- `COPY --from=阶段名 <源> <目标>`：从另一个阶段的文件系统拷贝。`--from` 也可以写镜像名，例如 `--from=nginx:latest`。
- 最终镜像**只包含目标阶段的层**。builder 阶段的所有层都不会进入最终镜像。

## --target：选择构建哪个阶段

一个 Dockerfile 可以有多个最终阶段：

```bash
docker build --target vla-body  -t vla-body:2.1.0  .
docker build --target vla-brain -t vla-brain:2.1.0 .
```

- 不写 `--target` 时，默认构建文件里的最后一个阶段。
- BuildKit 只构建目标阶段依赖的阶段。构建 `vla-body` 时，`vla-brain` 阶段会被跳过。

## 原文件的结构

```
vla-brain-env ──► builder      拷入源码，删测试，语法检查，结果放 /export
                     │
vla-brain-env ──► vla-brain ◄──┤ /export/brain
vla-body-env  ──► vla-body  ◄──┘ /export/body 和 openpi-client
```

- 一个 builder 服务两个最终阶段，整理代码的逻辑只写一遍。
- 两个最终阶段用不同的基础镜像：brain 需要 CUTLASS 等推理内核，body 需要相机 SDK。
- `build.sh` 用 `--target "vla-${k}"` 分别构建两个镜像。

## 动手试一试

```bash
mkdir -p ~/docker-lab/ch06/src/tests && cd ~/docker-lab/ch06
echo 'print("main")' > src/main.py
head -c 50000000 /dev/urandom > src/tests/big_fixture.bin     # 50 MB 测试数据

# 单阶段：先拷再删
cat > Dockerfile.single <<'EOF'
FROM python:3.12-slim
COPY src /app
RUN rm -rf /app/tests
EOF

# 多阶段：在 builder 里删，只拷结果
cat > Dockerfile.multi <<'EOF'
FROM python:3.12-slim AS builder
COPY src /src
RUN mkdir /export && cp -a /src/main.py /export/

FROM python:3.12-slim AS release
COPY --from=builder /export /app
EOF

docker build -f Dockerfile.single -t lab:ch06-single .
docker build -f Dockerfile.multi  -t lab:ch06-multi  .
docker images lab                                            # single 比 multi 大约 50 MB
```

两个镜像里都看不到 `tests` 目录，但 single 版本仍带着那 50 MB。
